# assets — cluster-LOD model corpus

This repo holds the shared 3D model library, cluster-LOD only, published over
GitHub Pages for the streaming-gltf demo and the spoint editor.

## Contents (cluster-only)

- `streaming-cluster/<Category>__<name>.cluster.glb` — 934 models baked to the
  EP_cluster_lod format (UV-aware spatial meshlet clusters + per-cluster LODs in
  one EXT_meshopt_compression GLB; see streaming-gltf `tools/bake-cluster.mjs`).
  These are the ONLY model bytes here — raw source GLBs and the old progressive
  `streaming/` bakes were removed.
- `manifest.json` — unified index `{ <Category>: [ { name, path, thumb } ] }`,
  `path = streaming-cluster/<name>.cluster.glb`. Regenerated by
  `docs/gen-manifest.js` from `git ls-files` (never hand-edited).
- `docs/` — the Pages gallery + `render-glb.js` (model-viewer thumbnailer) +
  `gen-manifest.js`.

## GitHub Pages

`.github/workflows/deploy-pages.yml` (push to `master`) thumbnails each cluster
GLB (LOD0 via model-viewer), regenerates `manifest.json`, copies
`streaming-cluster/` into `docs/`, and deploys to
`https://anentrypoint.github.io/assets/`. Consumers fetch `manifest.json` and
stream the `.cluster.glb` bytes cross-origin (GitHub Pages serves
`Access-Control-Allow-Origin: *`).

## Consumers

- streaming-gltf demo: discovers models from `manifest.json`, renders via the
  ModelPool cluster path (single WEBGL_multi_draw per model).
- spoint editor `apps/model-catalog`: model picker that lists `manifest.json`
  and places a chosen cluster GLB into a world via `PLACE_MODEL`.

## Re-bake

Baking is done in the streaming-gltf repo (`npm run bake:corpus` there writes
here). Do not add raw source GLBs back — the corpus is cluster-only.
